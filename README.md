# Shreya Turns Three

Dependency-free static birthday invitation for `http://shreya.hostapp.in`.

## Files

- `index.html` — invitation markup and social metadata
- `styles.css` — responsive design and animations
- `script.js` — client-side countdown to 19 August 2026, 7:30 PM IST
- `assets/` — optimized photograph, favicon, and calendar invitation

## Deploy

Commit all files in this directory to the repository connected to the domain.
The hosting document root should point to this directory and serve
`index.html`. No build command, server, framework, account, or environment
variable is required.

## Test

With Node.js installed, run:

```sh
npm test
```
